# AI Stock Simulator

가상 기업 뉴스가 시장에 반영되는 과정을 확인하는 개발용 예제다. 게임의 목표와 기능 범위는 [팀 제안서](PROPOSAL.md)에 정리했다.

## 실행

Node.js가 설치된 환경에서 저장소 루트 기준으로 실행한다.

```sh
node projects/ai-stock-simulator/demo.mjs
```

초기 현금은 100만 원이다. 예제 뉴스를 한 번 적용하면 삼송전자 주가는 50,000원에서 51,000원으로 바뀌고 한빛물류는 20,000원을 유지한다.

### 거래 화면 프로토타입

저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1 --directory projects/ai-stock-simulator`를 실행하고 [거래 화면](http://127.0.0.1:8000/ui/)을 연다. 국내 증권사 앱처럼 상승은 빨강, 하락은 파랑으로 표시한다. 종목을 선택하면 예제 시세·캔들 차트·보유 정보·주문 양식이 바뀐다. 차트에 포인터를 올리면 그 턴의 시가·고가·저가·종가·거래량이 보인다. 매수·매도와 수량을 골라 현재가 기준 주문 금액을 미리 볼 수 있다. 턴별 시가·고가·저가·거래량은 화면 확인용 예제 값이다.

## 개발 구조

| 파일 | 현재 역할 | 다음 개발 범위 |
| --- | --- | --- |
| `events/sample.mjs` | 뉴스 제목, 대상 종목 ID, 변동률 예제 제공 | AI 뉴스 생성과 응답 검증 |
| `market/engine.mjs` | 초기 시장·계좌 구성, 대상 종목 가격 계산 | 시간에 따른 시세 변화, 매매, 배당 |
| `demo.mjs` | 뉴스와 계산 전후 시세를 콘솔에 표시 | 차트·주문·자산 화면에서 시장 상태 사용 |

예제의 `changePercent`는 퍼센트 단위다. 2는 2% 상승을 뜻한다. 실제 게임의 주가 계산 규칙과 AI 공급자는 팀 협의로 정한다.
