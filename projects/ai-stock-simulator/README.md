# AI Stock Simulator

가상 기업 뉴스가 시장에 반영되는 과정을 확인하는 개발용 예제다. 게임의 목표와 기능 범위는 [팀 제안서](PROPOSAL.md)에 정리했다.

## 실행

Node.js가 설치된 환경에서 저장소 루트 기준으로 실행한다.

```sh
node projects/ai-stock-simulator/demo.mjs
```

초기 현금은 100만 원이다. 예제 뉴스 두 건을 순서대로 적용하면 삼송전자 주가는 50,000원 → 51,000원 → 52,020원으로 바뀌고 한빛물류는 20,000원을 유지한다.

## 개발 구조

| 파일 | 현재 역할 | 다음 개발 범위 |
| --- | --- | --- |
| `events/sample.mjs` | 뉴스 제목, 대상 종목 ID, 변동률 예제 제공 | AI 뉴스 생성과 응답 검증 |
| `market/engine.mjs` | 초기 상태 구성, 이벤트 검증, 가격·게임 상태 갱신 | 시간에 따른 시세 변화, 매매, 배당 |
| `demo.mjs` | 뉴스와 계산 전후 시세를 콘솔에 표시 | 차트·주문·자산 화면에서 시장 상태 사용 |

예제의 `changePercent`는 퍼센트 단위다. 2는 2% 상승을 뜻한다. 실제 게임의 주가 계산 규칙과 AI 공급자는 팀 협의로 정한다.

## 이벤트 적용

`applyEvent(stocks, event)`는 새 종목 배열을 반환한다.
`applyEventToGame(game, event)`는 해당 배열을 반영한 새 게임 상태를 반환한다.
호출자는 반환값을 다음 계산에 사용한다. 두 함수는 입력 상태를 수정하지 않는다.

이벤트에는 공백이 아닌 문자열 `headline`, 등록된 문자열 `stockId`,
유한한 숫자 `changePercent`가 필요하다. 잘못된 이벤트는 `TypeError`로 거부한다.
가격은 원 단위 반올림 후 최소 1원으로 계산한다. -100% 이하도 최저가 1원을 적용한다.
계산 중 무한대가 발생하거나 최종 가격이 안전한 정수 범위를 넘으면 `RangeError`로 거부한다.
경제적 변동률 상·하한은 팀 협의 항목이다.

## 테스트

저장소 루트에서 실행한다.

```sh
node --test projects/ai-stock-simulator/market/engine.test.mjs
```

연속 적용, 원본 보존, 반올림·최저가, 잘못된 이벤트와 계산 범위 초과를 검증한다.
